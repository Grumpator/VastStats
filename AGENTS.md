# VastStats contributor instructions

Before working on a chart, read [Chart standards](docs/chart-standards.md). Before changing dashboard formatting, labels, units, status colours, or icons, read [Dashboard display standards](docs/display-standards.md). Apply both when the work touches both areas.

If a proposed change would alter an established standard, explain the proposed change and get the user's explicit confirmation before changing the behavior or editing the standard. Once confirmed, update the relevant standards file in the same change as the implementation.

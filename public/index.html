How to read this dashboard

Fill = confirmed time. Green is confirmed running time, amber is confirmed idle time and grey is unknown time. Sectors fill clockwise from noon and use the elapsed part of the hour/day; future time is excluded. A half-green circle confirms running for half that elapsed time. Summary and device occupancy percentages use only observed data, so they may be higher than the green sector. The tooltip shows both. These measure box-time with any rental running, not the fraction of GPUs in use.

Number = runs during the hour/day. A stop and restart counts as two. A continuous run counts once in each circle it overlaps.

Border = recorded box state. Green means listed, grey unlisted, amber maintenance and red offline. Borders reflect recorded snapshots, not inferred durations.

Markers. A ring marks the current period. An amber dot marks any coverage below 100% in the elapsed portion. Fully grey circles have no data; future circles are excluded.

Device icons = latest snapshot. Chip plus count: GPUs; power: connection; tag: listing; spanner: maintenance; play/pause: running count; layers: stored count. Each device’s info button reveals timestamps and coverage.

Hover, focus or tap a circle for its details.
